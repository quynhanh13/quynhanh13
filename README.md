## 📌 Featured Projects

### 🚕 NYC Taxi Trip Duration Prediction

Analyzed **1.45M+ NYC taxi trips** using Python and Pandas to identify temporal, geographic, and trip-level patterns.

* Performed exploratory data analysis and feature engineering
* Built Linear Regression, Ridge Regression, Random Forest, and MLP models
* Applied cross-validation and hyperparameter tuning
* Conducted leakage audits and residual analysis
* Achieved approximately **31% lower RMSE** than linear baselines

### ❤️ AWS Heart Disease Prediction System

A cloud-based machine learning application for predicting heart disease risk.

* Developed a prediction API using **AWS Lambda and API Gateway**
* Implemented authentication with **Amazon Cognito**
* Stored patient and prediction data in **MySQL**
* Used **S3 and CloudFront** for the frontend
* Designed a serverless AWS architecture with multiple cloud services

### 🏨 Hotel Management System QA

Worked as a Software Quality Control Engineer on **F&B and Warehouse Management modules**.

* Designed test cases for new features, enhancements, and bug fixes
* Performed functional, regression, and data validation testing
* Used SQL to validate revenue, occupancy, F&B, and inventory data
* Investigated defects and documented reproducible steps
* Collaborated with BA and developers to clarify requirements and identify root causes
